# Plateforme d'archives de documents

## Installation locale

### Backend
```bash
cd backend
cp .env.example .env
npm install
npm run db:init
npm run dev
```

### Frontend
```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

## Services gratuits
- Neon (PostgreSQL)
- Cloudinary (fichiers)
- Brevo (emails)
- Render/Cloudflare Pages

Voir `.env.example`.
